# User Preferences & Constraints

## Interaction Style
- **Minimal Output:** Do not provide excessive documentation, setup, or testing files.
- **No Emojis:** Do not use emojis in code or terminal output.
- **PowerShell:** Use PowerShell for all shell commands.

## Architecture & Code
- **Follow Patterns:** Mimic the existing style, naming conventions, and architecture of the project.
- **No Temp Scripts:** Do not generate Python scripts for tasks; use native .NET tools or PowerShell.

## Verification & Safety (Critical)
- **Clean Diff:** When showing what you will change, keep the explanation extremely brief (1-2 sentences).
